# SourceReader

Read-only verified Python is a full-width, left-aligned document: file identity
above, source beneath, separated by shared spacing. Never put source in an action
group. Its code well uses tokenized monospace, padding and curvature, preserves
whitespace and scrolls horizontally within the reader. It does not verify, execute
or alter source bytes; the owning reader retains hash and UTF-8 checks.
