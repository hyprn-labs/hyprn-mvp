# FilePicker

A "Choose file" button that opens a hidden native file input. The selected filename is announced and wraps within its container. The input's accessible label names the import target, and the action works with Tab, Enter and Space. The disabled state follows the caller's guard. The page's action and empty label are in English; the operating system's chooser language is platform-controlled. The caller keeps its size, digest, scope and stale-response checks. Selecting a file saves nothing.
