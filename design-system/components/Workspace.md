# Workspace

WorkspaceShell accepts independent navigation, central canvas, context and assistant slots. The application owns guards, record identity and reads. NavigationRail uses the registry's grouped study destinations and explicit placeholders. At narrow widths the regions stack; all controls remain reachable. The current canvas remains the only model editor.

The 2026-10-17 [NavigationRail](NavigationRail.md) amendment replaces the earlier
flat destination list with the reference-style grouped, collapsible sidebar. Its
placeholder routes are explicit and guarded; all shared panel/canvas behavior stays.
