## Delivered boundary

Closed public sample preview/submit/read/control endpoints and matching existing owner
tools retain the full request, named categorical dimensions and explicitly supported
tuples, exact answer/configuration references, complete value/unit vectors, declared
seed/counts/targets, runtime identity, actual training/check partitions, run references,
result hashes, progress and bounded admission state. Preview performs no writes or
candidate execution. No new table, migration, dependency, scheduler or estimator
serialization was introduced. Existing configuration/run/receipt/AiiDA owners remain
authoritative. Configuration samples are saved immutable versions with family heads.

The restricted numerical worker appends seeded SciPy LHS batches to retained points.
It never reclassifies independent checks. The union is not claimed to be one
re-stratified LHS. Each original point uses the existing isolated scalar execution
path and stable command identity. An unknown accepted run is reconciled by lookup;
no replacement run is allocated. Unknown design artifacts stay uncertain and cannot
be relaunched by cancel/resume. Resume preserves deadline/budget and excludes another
active design in the same study. Recorded failures keep their partition/run identity.
Cancellation recovers the exact scalar receipt if acceptance committed before its
manifest association. A cancelled unresolved scalar continues occupying the operation
slot; control cannot adopt a conflicting command or free capacity by losing a run.

Reuse is explicit through `previous_operation_id`, with exact model/source/runtime,
numerical settings, named tuple mapping and full input values/units. Budget, target,
density and changed ranges do not discard compatible originals. Retained points
outside changed ranges remain evidence; only new points must lie in the new domain.
No global implicit sample cache is claimed. Prior ready versions remain untouched.

Limits: 8 tuples, 32 varied inputs/tuple, 128 retained points/operation, 3–64 training
and 2–64 independent checks/tuple; concurrency exactly 1. Additional attempts include
failures. Wall time is an elapsed admission deadline reserving each new point's hard
per-run allowance; it is not a total wall guarantee over preparation/AiiDA/recovery.
Cancel stops future acceptance after the current receipt is reconciled; it does not
kill an accepted native process. These semantics are documented in contracts/README.
Build/assessment of immutable surrogates and warm prediction remain V4 work.
