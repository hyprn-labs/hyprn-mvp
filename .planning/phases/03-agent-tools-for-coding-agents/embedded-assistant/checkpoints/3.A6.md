# Assistant spending visibility and compact conversation design

2026-10-20. Code `0fb9437`, final UI refinement `f7e48ec`. Local demonstration,
not full release qualification or human acceptance.

## Outcome and boundaries

- Additive `AssistantBudgetRead1` with human-only global and study-authorized reads.
  Aggregate installation costs never expose other studies or provider identities.
  The scoped endpoint rechecks access after awaited provider reads.
- Provider `usage.list_cost` supplies cumulative USD cents including subagents.
  Coalesced minute cache, four bounded reads at once, five-second per-read ceiling.
  Missing usage is null; refresh failure preserves an explicitly stale snapshot.
  No budget read sends a message, starts a session, runs a model or frees a reservation.
- Admission includes configured earlier usage. Existing conversation schema, reservations,
  per-study limits, delivery reconciliation, scientific sampling and surrogates unchanged.
- UI distinguishes original approval, provider budget, spend, remaining amount, reserved
  allowances and unallocated new-study capacity. Each study's remaining/cap stays visible.
  Converted remaining values are approximate, conversion date explicit; list cost is
  not an invoice and in-flight overshoot remains disclosed.
- Home replaces its action row with a compact labelled Create/Switch form. Cancel precedes
  primary Create/Open. Shared conversation styles fit short messages to content, align
  human bubbles right and Assistant prose left, and separate the study header.
  Enter uses the same Send guard; Shift+Enter adds a line, composition/repeated keydown
  does not submit. Table action labels and status badges remain one line; tables scroll.
