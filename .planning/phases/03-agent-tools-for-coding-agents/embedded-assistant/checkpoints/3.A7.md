## Outcome

- Each human turn receives its own cumulative provider cost plus fresh remaining shared
  allowance. No per-study reservation. Sequential study turns prevent double allocation;
  subagents within a turn remain available. Unknown usage/creation fails closed. Interrupted
  accepted messages reconcile before queued new messages. No session replacement or cost reset.
- Spending UI removed. Administrative read shape retained with shared remaining headroom
  and zero legacy reservations. Actual billing failures have a safe fixed diagnostic and
  permit only a new human request after funding, not automatic retry.
- Settings is a compact modal preserving workspace, exact selection and local drafts.
  Save/Cancel stays bottom-right; Escape cannot dismiss an active save. Theme stages until Save.
- Counts appear once; cards have compact horizontal actions. Removed conflicting legacy
  Home CSS. Unit labels/hints, field legends and persistence bars use shared styles.
- Load point belongs to Inputs; Plot against and Select outcomes belong to Outputs.
  Input ranges is the global action. Empty intermediate lanes collapse; narrow layouts stack
  controls with their section. Sampling, validation, prediction and version handlers unchanged.
