## Deviations, failures and corrections

- The check-runner integration conflict preserved both `native-environment` and `agent-ui` registrations; no registration was discarded.
- [Rule 1 — Bug] An earlier A attribution request could overwrite a later A visit after opening B. The generation fence fixes this; a delayed-response browser test covers it. Home read failures now use the common classifier; the existing request layer already invalidates sessions on 401.
- [Rule 1 — Bug] Visual review found the study creator below the title. The existing wrapping `actions` class now places it beside the title, with a bounding-box assertion at the reference viewport.
- [Rule 3 — Blocking check] `combined-static` failed once after that correction: 2 subcommands passed, the third failed, and 3 did not run because `check_ui_contract.py` demanded the old exact heading markup. A separate direct checker invocation failed for the same reason and stopped its commit command before staging. The updated assertion requires the study heading, its study name and the conditional creator chip together. The rerun passed all 6 subcommands. This checker already changed in the inherited implementation; maintaining it is a necessary extension of the task's listed files.
- The existing foundry and navigation doubles needed empty attribution read responses to keep their closed request registries correct; those compatibility changes are limited to their fixture handlers.
- The API caps names at 128 characters. The presentation-only long-name fixture deliberately uses 200 characters to satisfy the plan's stronger layout stress case without changing the public schema.
- DOM zoom checks passed, but visual inspection found Playwright full-page screenshots cropped at genuine tab zoom; ordinary viewport capture also produced an incorrect clip. Direct Chromium surface capture fixes the evidence, with no emulated viewport or altered zoom. The final images show complete wrapped names. Earlier incorrect captures remain distinguishable by scope identity in the evidence archive.
- Scratch cleanup initially encountered a read-only fixture directory. After evidence was preserved, only directories in the exact task-created scopes were made removable and cleanup completed. A redundant design-smoke cleanup found that its own runner had already removed that folder; no smoke scratch remains.
- The checkpoint verification shell initially shadowed its command-search variable during the file-existence loop and stopped before staging. The corrected loop uses a dedicated variable and completed normally.
- No browser or API case failed. Existing test-client deprecation and pytest marker warnings remain; one passing evidence-browser run logged a client-disconnect BrokenPipeError. No server error remained in the units reading report. These are recorded diagnostics, not suppressed test outcomes.
