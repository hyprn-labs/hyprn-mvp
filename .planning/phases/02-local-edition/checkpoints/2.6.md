## Implemented scope

- `deployment/locks/upstream.json` records the official upstream URL, exact commit, archive hash, size and AGPL licence. `acquire_upstream` verifies bytes before atomically publishing an owner-private 0400 cache entry. Corrupt, shared, writable or symlinked cache entries are refused without replacement. Interrupted downloads leave no published partial file; concurrent publication verifies the winning file.
- `deployment/locks/whatsopt-gems.json` records 176 exact archives: 170 platform-independent gems, three arm64 and three same-version amd64 variants. All 173 reference archives match official RubyGems published checksums. The three amd64 archives also match published checksums and the reference variants' dependencies and licences. No unmatched package or changed package version was substituted.
- `deployment/images/whatsopt-source.Dockerfile` builds from the verified original archive, digest-pinned Ruby and Node, Bundler 2.7.1 and Yarn 4.14.1. It requires the complete installed gem-cache filename/hash set to equal the selected platform lock and runs `yarn install --immutable`.
- `deployment/modeling_runtime.py` binds staged locks, recipes, relevant base-image pins and native source hashes to build identities. It refuses input drift during staging/building. Recorded source-image lookups verify that exact ID; they never substitute the latest tag. Verified images are reused without a Docker export, and immutable image-ID tags retain each built image. `modeling/rehearsal.py` and deployment setup record the source identity of the returned modeling image.
- `deployment/modeling.Dockerfile` builds offline from that source image. Corresponding source includes the original archive, all preserved patches, recipes, locks, pins and build identity. The exact Node licence accompanies the copied Node binary. Notices and `docs/legal/licensing.md` retain pending L1/L4 review and the existing AGPL scope.
- `deployment/checks.py` registers the must-pass `upstream` group. Its 25 tests cover acquisition refusal/reuse, interrupted and concurrent publication, exact baseline replay, template identity, build-input binding, staging drift and recorded-image identity.
