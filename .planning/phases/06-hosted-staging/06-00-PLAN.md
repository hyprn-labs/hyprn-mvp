# Repository and build hygiene

Scope: the implementation orchestrator owns `.gitignore`, `.dockerignore`,
`deployment/application_runtime.py` and its hardening tests, ADR-0014 and the
current coordination amendment. Preserve unrelated design-system and plan edits.

Outcome: private local files and source symlinks cannot enter the application
image through the existing source-build entry point. Repository-root Docker
contexts admit only the application recipe's source roots. Ignore rules cover
common credential/store/infra state files while allowing nonsecret templates.

Verification: `./hyprn-mvp dev check deployment-hardening`, with isolated fixtures
for forbidden files, symlink escape and source drift. Git ignore behavior checked
on synthetic path names without creating private material in the repository.

Limits: filename exclusions are defense in depth, not a complete secret-content
or Git-history scan. A publication scanner and final artifact inspection remain
part of the CI release batch. No live stores or credentials are modified.
