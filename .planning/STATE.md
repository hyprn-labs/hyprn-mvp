- ADR-0003 (supersedes ADR-0002): human-only actions are deleting saved records, archiving and restoring, and access management. Agents may do everything else within the delegating user's authority and limits, including creating studies (owned by the delegating user) and recording scientific reviews (labelled as recorded by an assistant). Draft and working material (including annotations) may be edited or deleted by an agent under revision checks; saved, versioned or read-only records never. Collection membership changes are allowed with exact versions and run pins kept; collection deletion is human-only. An agent's run submission whose configuration is not ready is refused with its reasons and no run created (human submissions unchanged). The Agent activity page with revoke replaces proposals.
- ADR-0005: an agent acting for a Reviewer may record scientific reviews (labelled as recorded by an assistant) and nothing else beyond reading. Method packages keep their rule: agents may draft package changes for a person to release but never edit released packages or the cases that grade them.
- Unified operations and explicit ownership (ADR-0004; requirement VER-04, planned): central invariant — an operation produces one authoritative outcome that every client can subsequently reference, inspect and act upon, without reconstructing or repeating the operation. Means: one consistent API for every client; every shared resource has one authoritative owner; operations that need shared identity, durability, consistency, observability or recovery expose stable identities and observable outcomes (the criterion is not the number of steps); clients and agents compose freely but never manage authoritative state, duplicate business orchestration or re-execute operations to reproduce shared results; domain state belongs to the application's domain modules, execution state to the execution engines (AiiDA authoritative for processes and artifacts; HYPRN MVP keeps references, associations, receipts and a status projection, never a parallel execution state machine), interaction state to the client or agent. Not mandated: one physical store, a durable workflow per operation, a central orchestrator for agent activity, or re-implementing what OpenMDAO, AiiDA or WhatsOpt provide.
